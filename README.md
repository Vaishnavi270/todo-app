# To-Do App Test Automation

Automated end-to-end tests for a To-Do application using Playwright + TypeScript.

## How to Run
1. Install dependencies: `npm install`
2. Run tests: `npx playwright test`
3. Run sanity tests only: `npx playwright test --grep "@sanity"`

## Features Tested
- Task creation
- Task completion
- Filtering tasks (All / Active / Completed)
- Clearing completed tasks
